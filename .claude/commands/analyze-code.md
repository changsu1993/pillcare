---
description: Analyze codebase structure and quality
---

Perform a comprehensive analysis of the PillCare codebase:

1. Project structure:
   - List all source files organized by directory
   - Identify main entry points
   - Show component hierarchy

2. Code quality metrics:
   - Total lines of code (by language)
   - TypeScript coverage (% of files using TS)
   - Component count (screens vs reusable components)
   - Unused imports or dead code

3. Dependencies:
   - List all npm packages
   - Identify outdated packages
   - Check for security vulnerabilities (if available)

4. Architecture review:
   - Identify potential code smells
   - Check for separation of concerns
   - Verify folder structure follows best practices

5. Testing coverage:
   - Count of test files
   - Estimated test coverage

Use the Filesystem MCP server to access all project files.
Present findings in a structured report with actionable recommendations.
